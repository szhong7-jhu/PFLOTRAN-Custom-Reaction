# PFLOTRAN-Custom-Reaction
Open Research
Data and Software Availability Statement
The numerical simulations presented in this study were conducted using PFLOTRAN, an open-source subsurface flow and reactive transport simulator (Hammond et al., 2014). The PFLOTRAN input files, model configurations, reaction parameters, mesh and material-property data, and scripts used for post-processing and figure generation are archived in Zenodo. The repository also contains the selected simulation outputs required to reproduce the figures and principal results presented in this study.

The simulations were performed using PFLOTRAN, available from the official PFLOTRAN source-code repository (https://bitbucket.org/pflotran/pflotran). Custom source-code modifications, where applicable, are included in the archived research materials.
